## Explicação das propriedades CSS

| Propriedade | O que faz | Por que foi utilizada |
|---|---|---|
| `box-sizing` | Define como a largura e a altura dos elementos são calculadas. | O valor `border-box` inclui padding e borda nas dimensões, tornando o layout mais previsível. |
| `margin` | Define o espaçamento externo de um elemento. | Remove a margem padrão do body, controla o espaço dos cards e ajusta as margens de outros elementos. |
| `padding` | Define o espaçamento interno de um elemento. | Afasta o conteúdo das bordas da página, dos títulos, dos cards e dos botões. |
| `font-family` | Define a família tipográfica. | Utiliza a fonte do sistema para oferecer uma tipografia legível. |
| `background` | Define o fundo de um elemento. | Diferencia o fundo da página, os cards comuns e os cards sem dono. |
| `color` | Define a cor do texto. | Mantém uma cor consistente para o texto e permite utilizar texto branco nos cards vermelhos. |
| `display` | Define o modelo de layout de um elemento. | Utiliza flexbox no cabeçalho e grid na área principal. |
| `justify-content` | Distribui os itens no eixo principal de um layout flexível. | Distribui os elementos do cabeçalho pelo espaço disponível. |
| `align-items` | Alinha os itens no eixo transversal do layout. | Alinha verticalmente os elementos do cabeçalho e controla o alinhamento em telas pequenas. |
| `flex-wrap` | Permite que os itens flexíveis passem para outra linha. | Evita que todos os elementos do cabeçalho precisem permanecer na mesma linha. |
| `gap` | Define o espaçamento entre os itens de um layout. | Cria uma separação uniforme entre os elementos. |
| `margin-bottom` | Define o espaço externo inferior. | Separa o cabeçalho e os itens da lista. |
| `grid-template-columns` | Define as colunas de um layout grid. | Mantém a página em uma única coluna e permite que ela se ajuste à largura disponível. |
| `min-width` | Define a largura mínima permitida para um elemento. | O valor `0` permite que a seção encolha conforme o espaço disponível. |
| `margin-top` | Define o espaço externo superior. | Remove a margem superior do título e separa o botão do restante do card. |
| `border-radius` | Arredonda os cantos de um elemento. | Mantém um padrão visual para títulos, cards e botões. |
| `border` | Define a espessura, o estilo e a cor da borda. | Delimita os cards e os botões. |
| `list-style` | Define os marcadores e o estilo visual de uma lista. | Remove os marcadores padrão da lista, pois cada card já possui sua própria apresentação. |
| `overflow-wrap` | Permite quebrar palavras compridas quando necessário. | Evita que títulos longos ultrapassem a largura dos cards em telas pequenas. |
| `font-size` | Define o tamanho do texto. | Estabelece uma apresentação consistente para os títulos e as informações dos responsáveis. |
| `line-height` | Define a altura das linhas de texto. | Melhora a legibilidade e o espaçamento entre linhas. |
| `border-left` | Define a borda esquerda de um elemento. | Mantém uma faixa colorida na lateral dos cards da coluna. |
| `font` | Permite definir várias características tipográficas em uma declaração. | Faz o botão herdar a tipografia utilizada pela página. |
| `font-weight` | Define o peso da fonte. | Destaca o texto dos botões para facilitar sua identificação. |
| `cursor` | Define a aparência do cursor do mouse. | Utiliza o cursor de interação sobre o botão. |
| `outline` | Desenha um contorno ao redor de um elemento. | Torna visível o foco de teclado nos controles. |
| `outline-offset` | Define a distância entre o elemento e seu contorno. | Separa o indicador de foco da borda do botão para facilitar sua visualização. |
| `text-align` | Define o alinhamento horizontal do texto. | Centraliza o texto do rodapé. |
| `max-width` | Define a largura máxima permitida para um elemento. | Ajuda a limitar os controles do cabeçalho em telas estreitas. |

## Variáveis CSS

As variáveis estão declaradas em `:root` para centralizar as cores e facilitar alterações futuras.

| Variável | Finalidade |
|---|---|
| `--fundo` | Define a cor de fundo da página. |
| `--cartao` | Define o fundo dos cards comuns e dos botões. |
| `--texto` | Define a cor principal do texto. |
| `--destaque` | Define a cor utilizada no indicador de foco do teclado. |
| `--cor-a-fazer` | Define a cor do título da coluna e da borda lateral dos cards. |
| `--cor-fazendo` | Mantém a cor originalmente definida para a coluna "Fazendo", que não está presente nesta versão da página. |
| `--cor-revisao` | Mantém a cor originalmente definida para a coluna "Revisão", que não está presente nesta versão. |
| `--cor-feito` | Mantém a cor originalmente definida para a coluna "Feito", que não está presente nesta versão. |
| `--cor-sem-dono` | Define o fundo dos cards sem responsável e a cor do texto dos botões sobre fundo branco. |
| `--texto-claro` | Define a cor branca utilizada nos textos sobre o fundo vermelho. |
| `--texto-escuro` | Mantém a variável original para texto escuro, embora não seja utilizada pelas regras atuais. |
